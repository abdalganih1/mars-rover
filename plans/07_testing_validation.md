# 07 — الاختبار والتحقق (Testing & Validation)

اختبر **بالترتيب**: الأردوينو وحده → الحساسات → الراسبيري وحده → التكامل.
⚠️ **السلامة:** ارفع العجلات عن الأرض في أول اختبار حركة.

---

## المرحلة 1 — الأردوينو منفصلاً (USB Serial)

> مؤقتاً للاختبار يمكنك توجيه البروتوكول إلى `Serial` بدل `btSerial` لتجربته عبر Serial Monitor،
> ثم أعده إلى `btSerial`. أو اربط HC-05 وأرسل عبر تطبيق بلوتوث طرفي.

- [ ] الترجمة تنجح؛ لا تحذير ذاكرة خطير.
- [ ] إقلاع: السيرفو يذهب 90°، المحركات ساكنة (RELEASE).
- [ ] `{"dir":"F","spd":150}` → 4 عجلات للأمام.
- [ ] `{"dir":"B","spd":150}` → للخلف.
- [ ] `{"dir":"SPIN_L","spd":200}` و `SPIN_R` → دوران بالمكان عكس بعض.
- [ ] `{"m1":200}` يدير محرك M1 فقط (تحقّق اتجاه كل محرك؛ صحّح INVERT إن لزم).
- [ ] `{"s1":0}` ثم `{"s1":180}` يحرّك السيرفو 1، و`s2` للسيرفو 2.
- [ ] `{"stop":true}` يوقف الكل.
- [ ] **Failsafe**: أرسل `dir F` ثم توقّف عن الإرسال → المحركات تقف خلال < 1s.

---

## المرحلة 2 — الحساسات (الأردوينو يرسل تيليمتري)

- [ ] يخرج سطر `{"T":..,"H":..,"G":..,"D":..,"R":..}` كل ~1s.
- [ ] T/H منطقيتان (DHT)، ليستا NaN.
- [ ] G يرتفع مع الغاز (بعد تسخين MQ2).
- [ ] D يطابق مسافة حقيقية (± بضع سم).
- [ ] R: جاف منخفض، مبلل مرتفع.
- [ ] heartbeat `{"hb":1}` كل ~2s.

---

## المرحلة 3 — الراسبيري منفصلاً (دون أردوينو)

- [ ] `python app.py` يقلع بلا استثناءات.
- [ ] فتح `http://<pi-ip>:5000` — الصفحة تحمّل.
- [ ] `/api/status` يرجع JSON صحيح.
- [ ] قائمة الحساسات تظهر في الإعدادات (إصلاح F5/F6).
- [ ] حقن قراءة يدوياً (محاكاة) → تظهر مع تاريخ + تحذير عند تجاوز العتبة (F7/F9).
- [ ] تشغيل سيناريو بخطوة `{"m1":150,"m2":150}` → يستدعي إرسال فعلي (F12).

> محاكاة قراءة دون عتاد: استدعِ `sensor_manager.update({"T":85})` من شِل بايثون وراقب الواجهة/التحذير.

---

## المرحلة 4 — التكامل الكامل (عبر HC-05)

- [ ] إقران HC-05 بالراسبيري (`bluetoothctl`، PIN غالباً 1234) وربط `/dev/rfcomm0`.
- [ ] الاتصال من الواجهة → حالة "متصل" + وصول heartbeat.
- [ ] أزرار الاتجاه (ضغط مطوّل → حركة، رفع → توقف).
- [ ] القراءات الحيّة من الأردوينو تظهر في لوحة الحساسات.
- [ ] الكاميرا تبثّ بالتوازي دون تأثّر التحكم.
- [ ] **اختبار قطع البلوتوث أثناء الحركة** → الأردوينو يوقف المحركات (failsafe)، والواجهة تُظهر انقطاعاً.

## استكشاف الأخطاء الشائعة

| العرض | السبب المحتمل | الحل |
|---|---|---|
| المحركات لا تدور | جمبر طاقة الشيلد / تغذية ناقصة | افحص بطارية الشيلد والأرضي المشترك |
| الأردوينو يعيد الإقلاع عند تحريك السيرفو | brownout | تغذية سيرفو مستقلة |
| HC-05 لا يستقبل | RX/TX معكوسان / لا divider | بدّل A4/A5، تأكد من المقاومات |
| قراءات DHT = NaN | لا pull-up / سلك / تردد قراءة عالٍ | 10kΩ + ≥1s بين القراءات |
| مسافة ultrasonic متذبذبة | تعارض SoftwareSerial | NewPing + اقرأ خارج نافذة الاستقبال |
| لا تظهر الحساسات بالواجهة | F5/F6 غير مصلَحة | طبّق إصلاحات app.py |
| السيناريو لا يحرّك شيئاً | تعارض M1/m1 (F12) | طبّع المفاتيح لصغيرة |
