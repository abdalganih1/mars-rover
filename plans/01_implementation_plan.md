# 01 — خطة التنفيذ الشاملة (Implementation Plan)

خارطة طريق مرحلية لتحويل المشروع من العتاد الحالي (L298N + محركان) إلى العتاد
المطلوب (شيلد L293D + 4 محركات + 2 سيرفو + HC-05 على SoftwareSerial + DHT/MQ2/Ultrasonic/Rain).

نفّذ المراحل **بالترتيب**. كل بند له تقرير في `Reports/`.

## 🔌 المرحلة 1 — العتاد والأسلاك (`03_pinmap_wiring.md`)

- [ ] **1.1** تركيب شيلد L293D فوق الأردوينو.
- [ ] **1.2** توصيل 4 محركات DC على منافذ M1..M4 بالشيلد.
- [ ] **1.3** توصيل السيرفوين على هيدر `SER1`/`SER2` (D9/D10) بالشيلد.
- [ ] **1.4** توصيل HC-05 عبر SoftwareSerial (A4/A5) **مع Voltage Divider** على خط Arduino→HC-05 RX.
- [ ] **1.5** توصيل الحساسات: Rain→A0، MQ2→A1، DHT→D2، HC-SR04 TRIG→A3 / ECHO→A2.
- [ ] **1.6** تغذية منفصلة لمحركات الشيلد (بطارية على طرف الـ EXT_PWR ونزع جمبر الطاقة عند اللزوم).
- [ ] **1.7** تغذية السيرفو من مصدر 5–6V مستقل (BEC) لتجنّب إعادة إقلاع الأردوينو.

## 💾 المرحلة 2 — كود الأردوينو (`02_arduino_firmware_l293d.md`)

- [ ] **2.1** استبدال تعريفات L298N بـ `AFMotor` (4 × `AF_DCMotor`).
- [ ] **2.2** نقل السيرفو إلى D9/D10.
- [ ] **2.3** إضافة `SoftwareSerial btSerial(A4, A5)` واستخدامه لكل تبادل JSON مع HC-05.
  - إبقاء `Serial` (USB) للتشخيص/البرمجة فقط.
- [ ] **2.4** استبدال LM35 بـ DHT (T + H)، وإضافة MQ2 (G)، Rain (R)، وإبقاء Ultrasonic (D).
- [ ] **2.5** منطق توجيه 4 عجلات (يسار = M1,M3 / يمين = M2,M4) لأوامر `dir`.
- [ ] **2.6** **Failsafe**: إيقاف كل المحركات إذا لم يصل أمر خلال `CMD_TIMEOUT` (مثلاً 800ms).
- [ ] **2.7** إزالة `delay()` المعطّلة من الحلقة (blink/flash) واستبدالها بـ `millis()`.
- [ ] **2.8** ضبط أحجام `JsonDocument` صغيرة + استخدام `F()` لتوفير الذاكرة (Uno = 2KB).
