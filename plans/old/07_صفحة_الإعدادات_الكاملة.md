# 07 - صفحة الإعدادات الكاملة

## الهدف
صفحة إعدادات شاملة تتيح التحكم بكل جانب من جوانب النظام: البلوتوث، الكاميرا، المحركات، الحساسات، السيناريوهات.

## الملفات
- `templates/settings.html`
- `static/css/settings.css`
- `static/js/settings.js`

## تصميم صفحة الإعدادات

### التخطيط العام (Tabs/Sections)

```
┌─────────────────────────────────────┐
│  ⬅ رجوع        ⚙️ الإعدادات        │
├─────────────────────────────────────┤
│ [🔵 بلوتوث] [📷 كاميرا] [⚡ محركات] │
│ [📡 حساسات] [🎬 سيناريو] [💾 عام]  │
├─────────────────────────────────────┤
│                                     │
│         محتوى التبويب المختار        │
│                                     │
│         (يتغير حسب التبويب)          │
│                                     │
├─────────────────────────────────────┤
│    [💾 حفظ الكل]  [↩ إعادة تعيين]    │
└─────────────────────────────────────┘
```

## JavaScript: تبديل التبويبات

```javascript
function switchTab(tabName) {
    // إخفاء كل التبويبات
    document.querySelectorAll('.settings-tab').forEach(tab => {
        tab.classList.remove('active');
    });
    // إزالة active من كل الأزرار
    document.querySelectorAll('.tab-btn').forEach(btn => {
        btn.classList.remove('active');
    });
    // إظهار التبويب المطلوب
    document.getElementById(`tab-${tabName}`).classList.add('active');
    document.querySelector(`[data-tab="${tabName}"]`).classList.add('active');
}
```

```javascript
async function saveAllSettings() {
    const settings = {
        bluetooth: {
            device_name: document.getElementById('bt-device-name-input').value,
            baudrate: parseInt(document.getElementById('bt-baudrate').value),
            auto_connect: document.getElementById('bt-auto-connect').checked,

            reconnect_attempts: parseInt(document.getElementById('bt-reconnect-attempts').value),
            reconnect_delay: parseInt(document.getElementById('bt-reconnect-delay').value)
        },
        camera: {
            color_mode: document.querySelector('input[name="color-mode"]:checked').value,
            brightness: parseInt(document.getElementById('cam-brightness').value),
            contrast: parseInt(document.getElementById('cam-contrast').value),
            // ... باقي الإعدادات
        },
        motors: {
            default_speed: parseInt(document.getElementById('mot-default-speed').value),
            // ...
        }
    };
    
    const response = await fetch('/api/config', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(settings)
    });
    
    if (response.ok) {
        showNotification('✅ تم حفظ الإعدادات', 'success');
    }
}
```
