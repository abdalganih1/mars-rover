# 01 - تحميل وتثبيت المكتبات

## الهدف
تثبيت جميع المكتبات المطلوبة على الراسبيري بي لضمان عمل النظام بالكامل.

## المتطلبات الأساسية
- Raspberry Pi OS (مُحدَّث)
- Python 3.9+
- pip3
- إنترنت متصل

## الخطوة 1: تحديث النظام
```bash
sudo apt-get update
sudo apt-get upgrade -y
```

## الخطوة 2: تثبيت مكتبات النظام المطلوبة
```bash
# مكتبات البلوتوث
sudo apt-get install -y bluetooth bluez bluez-tools python3-bluez
sudo apt-get install -y rfkill

# مكتبات الكاميرا والصور
sudo apt-get install -y libopencv-dev python3-opencv
sudo apt-get install -y libatlas-base-dev libjasper-dev libqtgui4 libqt4-test
sudo apt-get install -y libilmbase-dev libopenexr-dev libgstreamer1.0-dev
sudo apt-get install -y libavcodec-dev libavformat-dev libswscale-dev

# مكتبات السيريال
sudo apt-get install -y python3-serial

# أدوات بناء (مهمة لتجميع بعض المكتبات)
sudo apt-get install -y build-essential python3-dev

# مكتبات إضافية
sudo apt-get install -y python3-pip python3-venv
sudo apt-get install -y ffmpeg
```

## الخطوة 3: إنشاء بيئة افتراضية (Virtual Environment)
```bash
cd /home/user/program
python3 -m venv venv
source venv/bin/activate
```

## الخطوة 4: تثبيت مكتبات Python عبر pip

### ملف requirements.txt
```
# === الويب سيرفر ===
```

### أمر التثبيت
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## الخطوة 5: تثبيت Node.js (لو حاب تستخدمه لأجزاء Frontend)
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
npm install -g http-server  # سيرفر ملفات ثابتة (اختياري)
```

## الخطوة 6: إعداد صلاحيات البلوتوث والسيريال
```bash
# إضافة المستخدم لمجموعة البلوتوث
sudo usermod -aG bluetooth $USER

# إضافة المستخدم لمجموعة dialout (للسيريال)
sudo usermod -aG dialout $USER

# صلاحيات الكاميرا
sudo usermod -aG video $USER

# السماح بالوصول للبلوتوث بدون sudo
sudo setcap 'cap_net_raw,cap_net_admin+eip' $(readlink -f $(which hcitool))
sudo setcap 'cap_net_raw+eip' $(readlink -f $(which l2ping))
```

## الخطوة 7: تفعيل الكاميرا على الراسبيري
```bash
# تفعيل الكاميرا عبر raspi-config
sudo raspi-config
# Interface Options → Camera → Enable

# أو عبر الأمر:
sudo sed -i 's/^#start_x=.*/start_x=1/' /boot/config.txt
sudo sed -i 's/^gpu_mem=.*/gpu_mem=256/' /boot/config.txt
```

## الخطوة 8: إعداد Bluetooth RFCOMM
```bash
# تفعيل البلوتوث
sudo systemctl enable bluetooth
sudo systemctl start bluetooth

# تحقق من عمل البلوتوث
hciconfig hci0 up
```

## الخطوة 9: اختبار التثبيت
```bash
# اختبار بايثون
python3 -c "import cv2; print('OpenCV:', cv2.__version__)"
python3 -c "import serial; print('PySerial:', serial.__version__)"
python3 -c "import flask; print('Flask:', flask.__version__)"
python3 -c "import bluetooth; print('PyBluez: OK')"
python3 -c "import yaml; print('PyYAML: OK')"
python3 -c "import socketio; print('SocketIO: OK')"
```

## ملاحظات مهمة
- **opencv-python** قد يحتاج وقت طويل للتثبيت على الراسبيري (30-60 دقيقة). يمكن استخدام `opencv-python-headless` كبديل أسرع لكن بدون واجهة رسومية.
- **PyBluez** يحتاج `build-essential` و `python3-dev` للتجميع.
- تأكد من أن `gpu_mem` على الأقل 128MB (يفضل 256) لتشغيل الكاميرا.
- أعد تشغيل الراسبيري بعد تفعيل الكاميرا والصلاحيات.

## في حالة المشاكل

### مشكلة: OpenCV لا يرى الكاميرا
```bash
# تحقق من وجود الكاميرا
ls -la /dev/video*
vcgencmd get_camera
```

### مشكلة: البلوتوث غير موجود
```bash
hciconfig
# إذا فارغ، جرب:
sudo hciconfig hci0 up
```

### مشكلة: صلاحيات Serial مرفوضة
```bash
sudo chmod 666 /dev/rfcomm0
# أو أضف المستخدم لمجموعة dialout (الخطوة 6)
```
