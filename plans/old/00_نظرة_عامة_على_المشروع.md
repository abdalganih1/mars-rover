# 00 - نظرة عامة على المشروع

## اسم المشروع
**Raspberry Pi Robot Control System**

## الوصف
نظام متكامل للتحكم بروبوت عبر الراسبيري بي، يتصل بأردوينو عبر بلوتوث HC-05، ويوفر واجهة ويب للتحكم بالحركة والكاميرا والحساسات.

## البنية العامة

```
[متصفح الويب (Frontend)]
        │
        ▼ HTTP/WebSocket
[سيرفر Python Flask (Backend)] ──► [الراسبيري بي كاميرا (OpenCV)]
        │
        ▼ Serial (Bluetooth RFComm)
[أردوينو + HC-05]
        │
        ▼ PWM / Digital
[محركات DC + محركات Servo + حساسات]
```

## المكونات المادية
- **Raspberry Pi** (جهاز التحكم الرئيسي)
- **Arduino** (متحكم بالمحركات والحساسات)
- **HC-05** (وحدة بلوتوث للاتصال بين الراسبيري والأردوينو)
- **2× DC Motor** (للحركة أمام/خلف)
- **2× Servo Motor** (للتوجيه يمين/يسار)
- **حساسات متعددة** (حرارة، غاز، رطوبة، وأي حساس يُضاف لاحقاً)

## التقنيات المستخدمة
| المجال | التقنية |
|--------|---------|
| Backend | Python 3 + Flask + Flask-SocketIO |
| Serial | PySerial (عبر RFCOMM Bluetooth) |
| كاميرا | OpenCV (cv2) + picamera |
| Frontend | HTML5 + CSS3 + JavaScript |
| اتصال حي | WebSocket (Socket.IO) |
| بلوتوث | PyBluez + rfcomm |

## المنافذ
- **الويب سيرفر**: Port 5000 (Flask)
- **WebSocket**: نفس Port 5000 عبر Flask-SocketIO
- **Bluetooth Serial**: /dev/rfcomm0 (أو منفذ ديناميكي)

## بروتوكول الاتصال (راسبيري ↔ أردوينو)

### صيغة JSON
```json
{
  "M1": 200,
  "M2": 200,
  "S1": 90,
  "S2": 90,
  "T": null,
  "G": null,
  "H": null
}
```

### أزرار الحركة (أوامر سريعة)
| الأمر | المعنى |
|-------|--------|
| `F` | أمام (Forward) |
| `B` | خلف (Backward) |
| `L` | يسار (Left) |
| `R` | يمين (Right) |
| `S` | توقف (Stop) |

### صيغة الحساسات
```json
{"T": 25.5, "G": 0.2, "H": 60}
```
حيث:
- `T` = Temperature (حرارة °C)
- `G` = Gas (غاز)
- `H` = Humidity (رطوبة %)
