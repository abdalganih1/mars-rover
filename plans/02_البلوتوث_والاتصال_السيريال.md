# 02 - إعداد البلوتوث والاتصال السيريال

## الهدف
إنشاء وحدة اتصال بلوتوث مستقرة مع HC-05 تتضمن: بحث، اتصال، إعادة اتصال تلقائي، وإرسال/استقبال بيانات.

## الملفات المسؤولة
- `modules/bluetooth.py` — إدارة البلوتوث
- `modules/serial_comm.py` — الاتصال السيريال عبر RFCOMM

## تفاصيل الوحدة: `bluetooth.py`

### الكلاس: `BluetoothManager`

```python
class BluetoothManager:
    def __init__(self):
        self.target_address = None      # MAC Address الخاص بـ HC-05
        self.target_name = "HC-05"      # اسم الجهاز الافتراضي
        self.rfcomm_port = 0            # منفذ RFCOMM (0 أو 1)
        self.serial_port = "/dev/rfcomm0"
        self.is_connected = False
        self.auto_reconnect = True
        self.reconnect_attempts = 5
        self.reconnect_delay = 3        # ثواني بين كل محاولة
        self.discovered_devices = []    # قائمة الأجهزة المكتشفة
```

### الدوال المطلوبة

#### 1. `scan_devices(timeout=10) -> list`
- يبحث عن أجهزة البلوتوث القريبة
- يرجع قائمة بـ `[{"name": "HC-05", "address": "00:XX:XX:XX:XX:XX", "class": 0}]`
- يستخدم `bluetooth.discover_devices()`
- يعرض اسم كل جهاز عبر `bluetooth.lookup_name()`
- **Timeout قابل للتعديل** من الإعدادات

#### 2. `connect(address=None) -> bool`
- يتصل بالجهاز المحدد عبر MAC address
- لو `address=None` يستخدم آخر عنوان محفوظ
- ينشئ اتصال RFCOMM:
  ```bash
  sudo rfcomm bind 0 <MAC_ADDRESS> 1
  ```
- يفتح منفذ سيريال عبر PySerial:
  ```python
  self.serial_conn = serial.Serial(
      port='/dev/rfcomm0',
      baudrate=9600,        # الافتراضي لـ HC-05
      timeout=1,
      write_timeout=1
  )
  ```
- يحدث الحالة `is_connected = True`
- **Baud rate قابل للتغيير** من الإعدادات (9600, 19200, 38400, 57600, 115200)

#### 3. `disconnect() -> bool`
- يغلق الاتصال السيريال
- يحرر منفذ RFCOMM:
  ```bash
  sudo rfcomm release 0
  ```
- يحدث الحالة `is_connected = False`

#### 4. `auto_connect() -> bool`
- يحاول الاتصال تلقائياً بآخر جهاز محفوظ
- لو فشل، يعيد المحاولة `reconnect_attempts` مرات
- بين كل محاولة انتظر `reconnect_delay` ثانية
- يرسل حدث للواجهة بحالة الاتصال

#### 5. `send_data(data: str) -> bool`
- يرسل نص عبر السيريال
- يضيف `\n` في النهاية كفاصل
- يرجع `True` لو نجح
- يتعامل مع الأخطاء (جهاع غير متصل، timeout)

#### 6. `send_json(data: dict) -> bool`
- يحول dict إلى JSON string
- يرسله عبر `send_data()`
- مثال: `{"M1": 200, "S1": 90}`

#### 7. `read_data() -> str`
- يقرأ سطر من السيريال (حتى `\n`)
- يرجع النص المقروء
- **Non-blocking** مع timeout قصير

#### 8. `read_json() -> dict`
- يقرأ سطر ويحوله من JSON
- يرجع dict أو `None` لو فشل
- يستخدم لقراءة بيانات الحساسات من الأردوينو

#### 9. `get_status() -> dict`
- يرجع حالة الاتصال:
  ```python
  {
      "connected": True,
      "address": "00:XX:XX:XX:XX:XX",
      "name": "HC-05",
      "port": "/dev/rfcomm0",
      "baudrate": 9600,
      "signal_strength": -45  # dBm (لو متوفر)
  }
  ```

### خيوط الخلفية (Background Threads)

#### Thread: `connection_monitor`
- يعمل كل 5 ثواني
- يتحقق من استمرار الاتصال
- لو انقطع، يشغل `auto_connect()`
- يرسل حدث WebSocket بحالة الاتصال

#### Thread: `data_receiver`
- يعمل باستمرار
- يقرأ بيانات من السيريال (حساسات)
- يرسل البيانات عبر WebSocket للواجهة
- يحول JSON ويوزعه على المعالجات المناسبين

## تفاصيل الوحدة: `serial_comm.py`

### الكلاس: `SerialCommunicator`

هذه وحدة مساعدة تغلف PySerial:

```python
class SerialCommunicator:
    def __init__(self, port, baudrate=9600):
        self.port = port
        self.baudrate = baudrate
        self.connection = None
        self.lock = threading.Lock()  # قفل لمنع التعارض
```

### الدوال:
- `open() -> bool` — يفتح الاتصال
- `close() -> bool` — يغلق الاتصال
- `write(data: bytes) -> int` — يكتب بيانات خام
- `write_line(line: str) -> bool` — يكتب سطر نصي + `\n`
- `read_line(timeout=1) -> str` — يقرأ سطر
- `read_json(timeout=1) -> dict` — يقرأ JSON
- `is_open() -> bool` — هل الاتصال مفتوح؟
- `flush() -> None` — يمسح المخزن المؤقت

### أهمية الـ Lock (القفل)
بما أن عدة خيوط قد تكتب/تقرأ من السيريال:
- **lock** يضمن أن عملية إرسال واحدة تحدث في كل مرة
- يمنع تداخل الأوامر مثل `{S1:90}` مع `{M1:200}`

## إعدادات البلوتوث (في config.yaml)

```yaml
bluetooth:
  device_name: "HC-05"
  device_address: ""               # يُملأ تلقائياً عند الاتصال الأول
  rfcomm_port: 0
  serial_port: "/dev/rfcomm0"
  baudrate: 9600
  auto_connect_on_start: true
  auto_reconnect: true
  reconnect_attempts: 5
  reconnect_delay: 3
  scan_timeout: 10
  connection_timeout: 10
```

## تدفق الاتصال (Connection Flow)

```
1. تشغيل السيرفر
   ↓
2. تحميل الإعدادات من config.yaml
   ↓
3. auto_connect_on_start == true?
   ├── نعم → scan → connect → مراقبة
   └── لا → انتظار أمر من الواجهة
   ↓
4. المستخدم يضغط "بحث عن أجهزة"
   ↓
5. scan_devices() → عرض النتائج في الواجهة
   ↓
6. المستخدم يختار جهاز → connect(address)
   ↓
7. إنشاء RFCOMM → فتح Serial → متصل ✓
   ↓
8. خيط المراقبة يعمل + خيط القراءة يعمل
   ↓
9. إرسال أوامر / استقبال بيانات حساسات
```

## معالجة الأخطاء

| الخطأ | المعالجة |
|-------|----------|
| الجهاز غير موجود | إعلام المستخدم + إعادة محاولة |
| انقطع الاتصال أثناء العمل | auto_reconnect + إرسال S (توقف) للأردوينو |
| فشل إرسال أمر | إعادة محاولة 3 مرات + تسجيل الخطأ |
| بيانات مشوهة من السيريال | تجاهل + تسجيل تحذير |
| RFComm port مشغول | release + إعادة bind |

## اختبار الوحدة
```python
# اختبار البحث
bt = BluetoothManager()
devices = bt.scan_devices()
print(devices)

# اختبار الاتصال
bt.connect("00:XX:XX:XX:XX:XX")

# اختبار الإرسال
bt.send_json({"M1": 200, "M2": 200, "S1": 90})

# اختبار القراءة
data = bt.read_json()
print(data)
```
