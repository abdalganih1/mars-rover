## 📋 ملخص المشروع

نظام متكامل للتحكم بروبوت عبر **Raspberry Pi** متصل بـ **Arduino** عبر بلوتوث **HC-05**، يوفر واجهة ويب شاملة للتحكم بالحركة والكاميرا والحساسات والسيناريوهات.

### المكونات الأساسية
- **Backend**: Python 3 + Flask + Flask-SocketIO
- **اتصال**: PySerial + PyBluez (بلوتوث RFCOMM)
- **كاميرا**: OpenCV + picamera
- **Frontend**: HTML5 + CSS3 + JavaScript + WebSocket
- **أردوينو**: C++ مع ArduinoJson + Servo + SoftwareSerial

### الهاردوير
- 2× DC Motor (أمام/خلف) عبر L298N
- 2× Servo Motor (توجيه يمين/يسار) — 0° إلى 180°
- HC-05 بلوتوث
- حساسات: حرارة، غاز، رطوبة، مسافة، إلخ

## 📊 ملخص خطط التنفيذ

### الخطة 01: تحميل المكتبات
- تحديث النظام + تثبيت bluetooth, opencv, pyserial, flask
- إنشاء venv + requirements.txt
- صلاحيات البلوتوث والكاميرا

### الخطة 02: البلوتوث والاتصال السيريال
- `BluetoothManager`: بحث، اتصال، إعادة اتصال تلقائي
- `SerialCommunicator`: قراءة/كتابة مع قفل خيوط
- خيوط خلفية: مراقبة اتصال + قراءة حساسات

### الخطة 03: إعداد الكاميرا OpenCV
- `CameraManager`: بث حي + مرشحات (RGB, BGR, Grayscale, Binary)
- ضبط السطوع، التباين، التشبع
- كشف حواف، تمويه، تحجيم، ROI
- التقاط صور وتسجيل فيديو

### الخطة 04: بناء الـ Backend
- Flask + Flask-SocketIO على المنفذ 5000
- Routes: /, /settings, /api/status, /api/config, /api/command
- WebSocket events: move, stop, camera_frame, sensor_data
- 3 خيوط خلفية: كاميرا + حساسات + مراقبة اتصال

### الخطة 05: واجهة التحكم (Frontend)
- بث كاميرا مباشر في أعلى الصفحة
- أزرار اتجاهات (F, B, L, R) مع **ضغط مطول + توقف عند الرفع**
- Touch events + Mouse events + Keyboard (WASD)
- Sliders لتحكم بالسرعة

### الخطة 06: التحكم بالمحركات
- `MotorController`: DC motors (-255 to 255) + Servo (0-180°)
- أوامر JSON: `{"M1": 200, "M2": 200, "S1": 90, "S2": 90}`
- أوامر اتجاه: F, B, L, R, S, FL, FR, BL, BR, SPIN_L, SPIN_R
- توقف طوارئ + تدرج سرعة (ramp) + heartbeat

### الخطة 07: صفحة الإعدادات الكاملة
- 6 تبويبات: بلوتوث، كاميرا، محركات، حساسات، سيناريوهات، عام
- بحث بلوتوث + اتصال/قطع + إعادة اتصال تلقائي
- إعدادات الكاميرا: ألوان، مرشحات، دقة، FPS، ROI
- اختبار كل محرك/سيرفو بشكل مستقل
- إضافة/إزالة حساسات

### الخطة 08: إدارة الحساسات
- `SensorManager`: حساسات ديناميكية بكود حرفي
- تاريخ قراءات + رسم بياني + تحذيرات
- كل حساس: كود، اسم، وحدة، حد أدنى/أقصى، تحذير

### الخطة 09: نظام السيناريوهات
- إنشاء سيناريو: سلسلة خطوات + مدة كل خطوة
- تشغيل / إيقاف / تكرار (loop)
- تسجيل مباشر: سجّل حركاتك ثم أعد تشغيلها
- حفظ كملف JSON

### الخطة 10: كود الأردوينو
- استقبال JSON عبر HC-05
- تحكم بمحركات DC عبر L298N
- تحكم بسيرفو عبر Servo.h
- قراءة حساسات وإرسالها دورياً
- مكتبة ArduinoJson

### الخطة 11: اختبار وتكامل
- اختبار كل مكون على حدة
- قائمة فحص 25 نقطة
- تشغيل تلقائي عبر systemd
- استكشاف الأخطاء الشائعة

## 🔌 بروتوكول الاتصال

### راسبيري → أردوينو (أوامر)

**اتجاه بسيط:**
```json
{"CMD": "F", "SPD": 200}
```
`F`=أمام, `B`=خلف, `L`=يسار, `R`=يمين, `S`=توقف

**تحكم مباشر:**
```json
{"M1": 200, "M2": 200, "S1": 90, "S2": 90}
```
- M1, M2: -255 إلى 255 (DC motors)
- S1, S2: 0° إلى 180° (Servo)

### أردوينو → راسبيري (حساسات)
```json
{"T": 25.5, "G": 0.2, "H": 60, "D": 30.5}
```
- كل حرف = حساس مختلف (قابل للتوسيع)

## 📝 ملاحظات مهمة

1. **السلامة أولاً**: ارفع العجلات عن الأرض عند الاختبار الأول
2. **Voltage Divider**: لازم بين Arduino TX و HC-05 RX (5V → 3.3V)
3. **Touch Events**: استخدم `{ passive: false }` لمنع السلوك الافتراضي على الموبايل
4. **Heatbeat**: توقف تلقائي لو انقطع الاتصال
5. **Baud Rate**: الافتراضي 9600، تأكد من تطابق الراسبيري والأردوينو
