# 03 — خريطة الأرجل والأسلاك (Pin Map & Wiring)

> ⚠️ حرج: هذا الملف يحلّ تعارض أرجل HC-05 مع شيلد L293D. اقرأه قبل أي توصيل.

---

## 1. أرجل شيلد L293D (تصميم Adafruit Motor Shield v1 / نسخه)

الشيلد يحتوي شريحتَي **L293D** + رقاقة قفل **74HC595**، ويحجز هذه الأرجل **تلقائياً**
بمجرد تركيبه (لا يمكنك استخدامها لشيء آخر):

| الوظيفة | الرجل |
|---|---|
| 74HC595 — DIR_LATCH | **D12** |
| 74HC595 — DIR_CLK | **D4** |
| 74HC595 — DIR_EN | **D7** |
| 74HC595 — DIR_SER | **D8** |
| PWM المحرك M1 | **D11** |
| PWM المحرك M2 | **D3** |
| PWM المحرك M3 | **D6** |
| PWM المحرك M4 | **D5** |
| هيدر سيرفو SER1 | **D9** |
| هيدر سيرفو SER2 | **D10** |

**النتيجة:** الأرجل المحجوزة = `D3, D4, D5, D6, D7, D8, D9, D10, D11, D12`.

**الأرجل الحرّة:** `D2, D13, A0, A1, A2, A3, A4, A5`
**محجوز للبرمجة/USB (لا تلمسه):** `D0 (RX)`, `D1 (TX)`.

---

## 2. ⚠️ لماذا طلب "HC-05 على 3,4" غير ممكن

- `D4` = `DIR_CLK` للـ 74HC595 (يتحكم باتجاه كل المحركات).
- `D3` = PWM للمحرك M2.

أي توصيل لـ HC-05 على D3/D4 سيشلّ الشيلد. الفكرة الصحيحة من طلبك —
**عدم استخدام RX/TX العتاديين وإبقاؤهما للبرمجة، ووضع HC-05 على Serial منفصل** —
نحقّقها عبر `SoftwareSerial` لكن على **أرجل حرّة** بدل 3,4.

---

## 3. التوزيع المعتمد (Arduino Uno + شيلد L293D)

| المكوّن | رجل الأردوينو | ملاحظة |
|---|---|---|
| **رجل TX من HC-05 → A5** | **A5** (SoftwareSerial RX = يستقبل) | توصيل مباشر (3.3V يُقرأ كـ HIGH) |
| **رجل RX من HC-05 → A4** | **A4** (SoftwareSerial TX = يرسل) | **عبر Voltage Divider** (5V→~3.3V) |
| **Rain Sensor (AO)** | **A0** | تناظري — كما طلبت |
| **MQ2 (AO)** | **A1** | تناظري |
| **DHT (DATA)** | **D2** | رقمي + مقاومة pull-up 10kΩ بين DATA و VCC |
| **HC-SR04 TRIG** | **A3** | تُستخدم كرجل رقمية |
| **HC-SR04 ECHO** | **A2** | تُستخدم كرجل رقمية (ECHO 5V آمن للأردوينو) |
| **LED الحالة** | **D13** | الـ LED المدمج |
| 4× DC Motors | منافذ M1..M4 بالشيلد | عبر مكتبة AFMotor |
| 2× Servo | هيدر SER1 (D9), SER2 (D10) | مكتبة Servo |

> A0–A5 يمكن استخدامها كأرجل رقمية في كود الأردوينو (`A2`, `A3`, `A4`, `A5`).

---

## 4. Voltage Divider لخط Arduino(A5) → HC-05 RX

رجل RX في HC-05 تتحمّل 3.3V فقط. خفّض 5V القادمة من الأردوينو:

```
Arduino A4 (TX) ──[ R1 = 1kΩ ]──┬── HC-05 RX
                                 │
                              [ R2 = 2kΩ ]
                                 │
                                GND
```
الناتج ≈ 5V × 2k/(1k+2k) ≈ 3.33V. (خط HC-05 TX → A5 يُترك مباشراً).

---

## 5. التغذية (Power) — مهم لتجنّب إعادة الإقلاع

- **محركات DC**: تغذية خارجية (بطارية 6–12V حسب المحركات) على طرف الطاقة بالشيلد.
  انزع جمبر الطاقة (`PWR`) إن كنت تغذّي الشيلد منفصلاً عن الأردوينو.
- **السيرفو**: على شيلد v1 تأخذ طاقتها من 5V الأردوينو → سحب التيار العالي قد يسبب Brownout.
  **موصى به: تغذية السيرفو من مصدر 5–6V مستقل (BEC)** مع توحيد الأرضي (GND مشترك).
- **HC-05**: VCC على 5V (معظم الموديولات بها منظّم داخلي)، GND مشترك.
- **DHT/MQ2/Rain/HC-SR04**: VCC=5V، GND مشترك.

> ⚠️ MQ2 يسخّن ويسحب تياراً ملحوظاً؛ لا تغذّه من رجل إشارة. استخدم 5V/GND مباشرة.

---

## 6. مخطّط أرضي موحّد (Common Ground)

كل المصادر (أردوينو، بطارية المحركات، تغذية السيرفو، HC-05) **يجب أن تشترك في GND واحد**،
وإلا لن تعمل الإشارات بشكل صحيح.

---

## 7. ملاحظات تعارض المؤقّتات/المقاطعات (Timers/Interrupts)

- `SoftwareSerial` يعطّل المقاطعات أثناء الإرسال/الاستقبال → قد يسبب:
  - رجفة في السيرفو (jitter).
  - قراءات `pulseIn` خاطئة للـ ultrasonic.
- **التخفيف**: اقرأ الـ ultrasonic عندما لا يكون هناك استقبال نشط، واستخدم `NewPing`،
  وأبقِ baud الـ HC-05 على 9600، ولا تقرأ كل الحساسات في كل لفّة.
- مكتبة `Servo` تستخدم Timer1، والشيلد v1 يستخدم Timer0/Timer2 لـ PWM المحركات →
  تشغيل سيرفوين على D9/D10 مع المحركات **مدعوم رسمياً** من Adafruit.

---

## 8. مرجع سريع (نسخة للصق في أعلى كود الأردوينو)

```cpp
// ---- Pin map (Uno + L293D shield) ----
// Shield (auto): D3,D4,D5,D6,D7,D8,D11,D12 = motors/latch ; D9,D10 = servos
// HC-05  : SoftwareSerial btSerial(A5, A4) → RX=A5 (من HC-05 TX) ، TX=A4 (إلى HC-05 RX عبر divider)
// Rain   : A0 (analog)
// MQ2    : A1 (analog)
// DHT    : D2 (digital, 10k pullup)
// HC-SR04: TRIG=A3, ECHO=A2
// Status : D13 (builtin LED)
```
